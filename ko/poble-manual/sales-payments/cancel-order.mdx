현재 주문을 취소하고 사유를 기록합니다.

**경로:** POS 기기 → 판매 화면 → Cancel Order

<Steps>
<Step title="Cancel Order 선택">

현재 주문을 확인한 뒤 판매 화면 왼쪽 하단의 **Cancel Order**를 선택하세요.

</Step>
<Step title="취소 사유 입력">

**Cancel Order** 창에서 주문 오류나 고객 요청 등 취소하는 이유를 입력하세요.

<Frame caption="사유 입력란, Cancel, Confirm이 있는 Cancel Order 창">
  <img src="/images/sales-payments/cancel-order.png" alt="사유 입력란, Cancel, Confirm이 있는 Cancel Order 창" />
</Frame>

</Step>
<Step title="취소 확정">

취소를 진행하려면 **Confirm**을 선택하세요. 취소하지 않고 창을 닫으려면 **Cancel**을 선택하세요.

</Step>
</Steps>

<Warning>
**Cancel Order**는 현재 주문 전체를 취소합니다. 상품 하나만 제거하려면 해당 상품의 수량 설정과 삭제 아이콘을 사용하세요.
</Warning>
