POS 메인 페이지에서 판매 화면을 엽니다.

**경로:** POS 기기 → 메인 화면 → Start Sales

<Steps>
<Step title="매장 확인">

POS 메인 페이지에서 주문을 받기 전에 매장명을 확인하세요.

<Frame caption="Start Sales 버튼이 있는 POS 메인 페이지">
  <img src="/images/sales-payments/start-sales.png" alt="Start Sales 버튼이 있는 POS 메인 페이지" />
</Frame>

</Step>
<Step title="주문 접수 시작">

**Start Sales**를 선택해 판매 화면을 여세요.

</Step>
</Steps>
