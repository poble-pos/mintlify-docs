회사 메뉴 상품을 Coffee, Food, Drinks 등의 카테고리로 정리합니다.

**경로:** 관리 화면 → 회사 화면 → POS → Menu Settings

<Steps>
<Step title="카테고리 생성 시작">

카테고리 목록 위의 **Create Category**를 선택하세요.

<Frame caption="회사 메뉴 카테고리와 Create Category 버튼">
  <img src="/images/menu-management/company-category-list.png" alt="회사 메뉴 카테고리와 Create Category 버튼" />
</Frame>

</Step>
<Step title="카테고리 정보 입력">

**Name**을 입력하세요. 필요하면 이미지, **POS Display Name**, **Description**을 추가하세요.

<Frame caption="Available Stores가 포함된 Create Category 양식">
  <img src="/images/menu-management/company-create-category.png" alt="Available Stores가 포함된 Create Category 양식" />
</Frame>

</Step>
<Step title="사용할 매장 선택 후 생성">

**Available Stores**에서 해당 카테고리를 사용할 지점을 선택하고 **Create**를 누르세요.

</Step>
</Steps>

<Tip>
직원이 상품을 빨리 찾을 수 있도록 카테고리 이름을 명확하게 정하세요.
</Tip>
