회사 메뉴 상품을 만들고 이름, 가격, 카테고리 등의 정보를 수정합니다.

**경로:** 관리 화면 → 회사 화면 → POS → Menu Settings

<Steps>
<Step title="카테고리 선택">

목록에서 카테고리를 선택하면 옆에 상품이 표시됩니다. 상품을 추가하려면 **Create Menu Item**을 선택하세요.

<Frame caption="Coffee 카테고리의 상품과 Create Menu Item 버튼">
  <img src="/images/menu-management/company-item-list.png" alt="Coffee 카테고리의 상품과 Create Menu Item 버튼" />
</Frame>

</Step>
<Step title="상품 정보 입력">

**Item Type**을 선택하고 **Name**, **Price**를 입력하세요. 필요에 따라 이미지, **POS Display Name**, **Description**, **Tags**, 바코드 정보를 추가하세요. **Tax Options**를 확인하고 **Create**를 선택하세요.

<Frame caption="회사 관리 화면의 Create Menu Item 양식">
  <img src="/images/menu-management/company-create-item.png" alt="회사 관리 화면의 Create Menu Item 양식" />
</Frame>

</Step>
<Step title="기존 상품 수정">

카테고리에서 상품을 열고 필요한 항목을 수정하세요. 다른 카테고리로 이동하려면 **Change Category**를 사용하고 페이지의 버튼으로 변경 사항을 적용하세요.

<Frame caption="회사 메뉴 상품 상세 정보와 Change Category 버튼">
  <img src="/images/menu-management/company-edit-item.png" alt="회사 메뉴 상품 상세 정보와 Change Category 버튼" />
</Frame>

</Step>
</Steps>

<Note>
생성 화면과 수정 화면의 항목명은 다를 수 있습니다. 적용 전에 선택한 상품과 가격을 확인하세요.
</Note>
