---
title: "메뉴 관리"
description: "매장 메뉴를 만들고 옵션과 POS 메뉴를 설정합니다."
---

관리 화면 또는 POS 기기에서 POBLE 메뉴를 생성하고 관리하세요. 작업 중인 화면에 맞는 가이드를 선택하세요.

## 작업 환경 선택

| 작업 환경 | 가이드 내용 |
| --- | --- |
| 관리 화면 — 회사 | 회사 메뉴 카테고리, 상품, 사용 가능 매장, 옵션 그룹 |
| 관리 화면 — 매장 및 가맹점 | 선택한 지점에 연결된 카테고리와 상품 |
| POS 기기 | POS에서 직접 관리하는 카테고리, 상품, 옵션 |
| 메뉴 구성 | 옵션 연결, 프린터 연결, 선불 상품, 메뉴 배치, 할인 |

<Tip>
카테고리를 먼저 만든 뒤 상품과 옵션 그룹을 생성하세요. 옵션을 상품에 연결한 후 POS 메뉴 레이아웃을 배치하세요.
</Tip>
