POS에서 카테고리를 추가하거나 사용 가능한 기존 카테고리를 찾습니다.

**경로:** POS 기기 → Menu Management → Menu Setup

<Steps>
<Step title="카테고리 생성 시작">

**Menu Setup**의 **Categories** 옆 **+**를 선택하세요.

</Step>
<Step title="카테고리 정보 입력">

**Create Category**에서 **Item Name**에 필수 카테고리 이름을 입력하세요. 필요하면 이미지, **POS Display Name**, **Description**을 추가하세요.

<Frame caption="POS의 Create Category 창">
  <img src="/images/menu-management/pos-create-category.png" alt="POS의 Create Category 창" />
</Frame>

</Step>
<Step title="카테고리 생성 또는 검색">

새 카테고리를 저장하려면 **Create**를 선택하세요. 기존 카테고리를 선택하려면 **Browse Available Categories**를 사용하세요.

</Step>
</Steps>
