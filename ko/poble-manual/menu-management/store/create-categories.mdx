선택한 매장에 메뉴 카테고리를 만듭니다.

**경로:** 관리 화면 → 선택한 매장 → POS → Menu Settings

<Steps>
<Step title="카테고리 양식 열기">

올바른 매장을 선택했는지 확인한 뒤 **Create Category**를 누르세요.

</Step>
<Step title="카테고리 정보 입력">

**Name**을 입력하세요. 필요하면 이미지, **POS Display Name**, **Description**을 추가하세요.

<Frame caption="선택한 매장의 Create Category 양식">
  <img src="/images/menu-management/store-create-category.png" alt="선택한 매장의 Create Category 양식" />
</Frame>

</Step>
<Step title="카테고리 생성">

정보를 확인하고 카테고리 양식의 **Create**를 선택하세요.

</Step>
</Steps>

<Note>
회사 카테고리 양식에는 **Available Stores**가 있습니다. 매장 화면에서는 생성 전에 헤더의 지점을 확인하세요.
</Note>
