고객이 주문을 맞춤 구성할 수 있도록 옵션 그룹을 상품에 연결합니다.

**경로:** POS 기기 → Menu Management → Menu Setup → Option Mapping

<Steps>
<Step title="Option Mapping 열기">

**Menu Setup**에서 **Option Mapping**을 선택해 **Manage Item Options**를 여세요.

</Step>
<Step title="메뉴 상품 선택">

**Item Category**를 선택한 뒤 설정할 상품을 선택하세요.

</Step>
<Step title="옵션 그룹 선택 및 정렬">

필요한 **Option Groups**를 선택하세요. **Selected Option Groups**를 확인하고 드래그해 순서를 바꾸세요.

<Frame caption="카테고리, 상품, 선택한 옵션 그룹이 표시된 Manage Item Options">
  <img src="/images/menu-management/option-mapping.png" alt="카테고리, 상품, 선택한 옵션 그룹이 표시된 Manage Item Options" />
</Frame>

</Step>
<Step title="연결 저장">

선택한 상품과 옵션 그룹을 확인하고 **Save**를 선택하세요.

</Step>
</Steps>

<Warning>
이 화면에서 옵션을 설정하면 기존 설정을 덮어쓴다고 안내되어 있습니다. 저장 전에 선택한 상품과 현재 옵션을 확인하세요.
</Warning>
