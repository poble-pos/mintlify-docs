상품이 올바른 프린터로 전송되도록 프린터 그룹을 관리합니다.

**경로:** POS 기기 → Menu Management → Menu Setup → Printer Mapping

<Steps>
<Step title="Printer Mapping 열기">

**Menu Setup**에서 **Printer Mapping**을 선택해 **Manage Printer Groups**를 여세요.

</Step>
<Step title="프린터 그룹 만들기">

**Create Group**을 선택하세요. **Create Printer Category** 양식에 **Name**, **Description**을 입력하세요.

<Frame caption="Manage Printer Groups와 Create Printer Category 양식">
  <img src="/images/menu-management/printer-mapping.png" alt="Manage Printer Groups와 Create Printer Category 양식" />
</Frame>

</Step>
<Step title="출력 옵션 확인">

추가 출력이 필요하면 **Extra Print Count**를 확인하세요. 양식에 표시된 버튼으로 그룹 생성을 완료하세요.

</Step>
<Step title="프린터 배정 확인">

그룹과 배정 설정을 확인해 상품이 원하는 프린터로 전송되도록 하세요.

</Step>
</Steps>

<Note>
Printer Mapping은 프린터 그룹과 배정을 관리합니다. 하드웨어와 연결 설정은 POS의 프린터 설정을 사용하세요.
</Note>
