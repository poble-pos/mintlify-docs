구독 설정 중 선택한 요금제에 추가 기능을 더할 수 있습니다.

## 추가 기능 선택

<Steps>
<Step title="추가 기능 확인">

**Customise with Add-ons**를 여세요. 예시에는 키오스크, Uber Eats 연동, 추가 POS 기기, KDS, 테이블 예약, 대기 명단, 테이블, 로열티, 온라인 주문 기능이 있습니다.

</Step>
<Step title="필요한 기능 선택">

비즈니스에 필요한 추가 기능을 선택하세요. 각 항목의 설명과 표시된 월 요금을 확인하세요.

</Step>
<Step title="주문 요약 확인">

**Order Summary**와 **Total**에서 선택한 요금제와 추가 기능을 확인하세요.

</Step>
<Step title="결제 정보로 이동">

주문 요약 아래에 표시된 체험 또는 결제 버튼으로 결제 화면에 이동하세요.

</Step>
</Steps>

<Frame caption="추가 기능을 선택하고 구독 합계를 확인합니다.">

</Frame>

<Tip>
추가 기능을 선택한 뒤 합계를 확인해 선택 항목에 따른 구독 요금을 파악하세요.
</Tip>
