계정을 만들고 첫 매장과 구독을 설정합니다.

회사 생성 → 매장 설정 → 요금제 선택 → 추가 기능 선택 → 결제 설정 순서로 진행하세요.

</Card>
<Card title="매장 설정" href="/ko/poble-manual/getting-started/set-up-your-store">
