회사를 생성한 뒤 POBLE 계정에 연결할 첫 매장을 설정하세요.

## 매장 설정

<Steps>
<Step title="매장 정보 입력 방식 선택">

**Set up store**에서 회사와 매장 정보가 같으면 **Create a store with the same details as the company**를 선택하세요. 다르면 확인란을 해제하고 매장 정보를 입력하세요.

</Step>
<Step title="매장 로고 추가">

로고 업로드 버튼으로 매장 이미지를 추가하세요.

</Step>
<Step title="매장 정보 확인">

설정 중인 지점의 정보가 맞는지 확인하고 구독 설정 단계로 이동하세요.

</Step>
</Steps>

<Frame caption="첫 매장을 생성하고 매장 정보와 로고를 추가합니다.">

</Frame>

<Note>
추가 지점은 나중에 **Stores → Add Store**에서 생성할 수 있습니다.
</Note>
