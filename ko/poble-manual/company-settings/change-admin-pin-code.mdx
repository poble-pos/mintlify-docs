**Profile**에서 관리자 POS PIN을 변경하세요. 화면에는 접근 가능한 매장별 PIN 입력란이 표시됩니다.

## 관리자 PIN 변경

<Steps>
<Step title="접근 가능한 매장 열기">

**Profile**을 선택하고 **Accessible Stores** 탭을 여세요.

</Step>
<Step title="새 PIN 입력">

해당 매장을 찾아 **Pos Pin Code**에 새 PIN을 입력하세요.

</Step>
<Step title="변경 사항 적용">

해당 매장 옆의 **Update**를 선택하세요.

</Step>
</Steps>

<Frame caption="프로필에서 매장의 POS PIN을 변경합니다.">
  <img src="/images/company-settings/change-admin-pin-code.png" alt="프로필에서 매장의 POS PIN을 변경합니다." />
</Frame>

<Tip>
PIN은 다른 사람에게 공개하지 말고, 예시 이미지처럼 추측하기 쉬운 값은 피하세요.
</Tip>
