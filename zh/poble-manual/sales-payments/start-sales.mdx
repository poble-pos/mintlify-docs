从 POS 主页面打开销售界面。

**位置：** POS 设备 → 主屏幕 → Start Sales

<Steps>
<Step title="检查门店">

在 POS 主页面接单前，请检查门店名称。

<Frame caption="包含 Start Sales 按钮的 POS 主页面">
  <img src="/images/sales-payments/start-sales.png" alt="包含 Start Sales 按钮的 POS 主页面" />
</Frame>

</Step>
<Step title="开始接单">

选择 **Start Sales** 打开销售界面。

</Step>
</Steps>
