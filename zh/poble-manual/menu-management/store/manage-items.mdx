管理单家门店的菜单分类和商品。

**位置：** 管理后台 → 所选门店 → POS → Menu Settings

<Steps>
<Step title="选择分类">

打开所选门店的 **Menu Settings**，选择要管理的分类。

</Step>
<Step title="添加菜单商品">

选择 **Create Menu Item**，填写商品名称、价格、分类等所需信息，并使用表单控件完成创建。

<Frame caption="门店商品列表与 Create Menu Item 按钮">
  <img src="/images/menu-management/store-create-item.png" alt="门店商品列表与 Create Menu Item 按钮" />
</Frame>

</Step>
<Step title="编辑已有商品">

从列表打开商品，按需修改名称、价格、分类等设置。检查并应用所选门店的更改。

</Step>
<Step title="编辑分类">

要修改分类本身，请打开名称旁的 **…** 菜单并选择 **Edit Category**。

<Frame caption="包含 Edit Category 与 Delete Category 的分类菜单">
  <img src="/images/menu-management/store-edit-menu.png" alt="包含 Edit Category 与 Delete Category 的分类菜单" />
</Frame>

</Step>
</Steps>

<Tip>
使用 **Edit Category** 修改分类；修改商品信息时，请打开相应商品。
</Tip>
