为所选门店创建菜单分类。

**位置：** 管理后台 → 所选门店 → POS → Menu Settings

<Steps>
<Step title="打开分类表单">

确认所选门店正确后，选择 **Create Category**。

</Step>
<Step title="填写分类信息">

填写 **Name**。按需添加图片、**POS Display Name** 和 **Description**。

<Frame caption="所选门店的 Create Category 表单">
  <img src="/images/menu-management/store-create-category.png" alt="所选门店的 Create Category 表单" />
</Frame>

</Step>
<Step title="创建分类">

检查信息，然后在分类表单中选择 **Create**。

</Step>
</Steps>

<Note>
公司分类表单包含 **Available Stores**。在门店视图中创建前，请检查页眉中的门店。
</Note>
