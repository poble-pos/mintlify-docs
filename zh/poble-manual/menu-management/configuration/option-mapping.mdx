将选项组关联至菜单商品，让顾客定制订单。

**位置：** POS 设备 → Menu Management → Menu Setup → Option Mapping

<Steps>
<Step title="打开 Option Mapping">

在 **Menu Setup** 中选择 **Option Mapping**，打开 **Manage Item Options**。

</Step>
<Step title="选择菜单商品">

选择 **Item Category**，然后选择要配置的商品。

</Step>
<Step title="选择并排列选项组">

选择所需的 **Option Groups**。检查 **Selected Option Groups**，并拖动调整顺序。

<Frame caption="显示分类、商品及已选选项组的 Manage Item Options">
  <img src="/images/menu-management/option-mapping.png" alt="显示分类、商品及已选选项组的 Manage Item Options" />
</Frame>

</Step>
<Step title="保存关联">

检查所选商品和选项组，然后选择 **Save**。

</Step>
</Steps>

<Warning>
界面提示，此处设置选项会覆盖现有设置。保存前请检查所选商品及其当前选项。
</Warning>
