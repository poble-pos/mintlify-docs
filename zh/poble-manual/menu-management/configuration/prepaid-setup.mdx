通过 POS 菜单工具创建礼品卡或预付商品。

**位置：** POS 设备 → Menu Management → Prepaid Setup

<Steps>
<Step title="打开 Prepaid Setup">

在菜单管理侧边栏选择 **Prepaid Setup**，然后选择 **+** 开始添加商品。

</Step>
<Step title="选择商品类型">

在 **Basic Info** 中按需选择 **Gift Card** 或 **Prepaid**。

<Frame caption="包含 Gift Card 与 Prepaid 选项的 Prepaid Setup 表单">
  <img src="/images/menu-management/prepaid-setup.png" alt="包含 Gift Card 与 Prepaid 选项的 Prepaid Setup 表单" />
</Frame>

</Step>
<Step title="填写商品信息">

选择 **Category**，填写 **Item Name**、**Price** 和 **Tax Option**。按需添加图片、条码、**POS Display Name** 和 **Description**。

</Step>
<Step title="检查并创建">

按需检查 **Print Options** 和 **Advanced Options**，然后选择 **Create**。

</Step>
</Steps>
