按员工的操作习惯排列分类和商品按钮。

**位置：** POS 设备 → Menu Management → Menu Layout

<Steps>
<Step title="打开 Menu Layout">

在菜单管理侧边栏选择 **Menu Layout**。

</Step>
<Step title="选择显示设置">

检查 **Preview Mode**、**Select Layout Type** 和 **Font Size**。需要管理显示的组时，使用 **Manage Groups**。

<Frame caption="包含分类组、商品网格和布局控件的 POS Menu Layout">
  <img src="/images/menu-management/menu-layout.png" alt="包含分类组、商品网格和布局控件的 POS Menu Layout" />
</Frame>

</Step>
<Step title="排列菜单">

选择要调整的组，拖动商品按钮更改位置。使用商品搜索和分类选择器查找要添加到布局的商品。

</Step>
<Step title="检查结果">

在预览中检查分类顺序和商品位置，并使用界面控件应用更改。

</Step>
</Steps>

<Tip>
将常用分类和商品放在员工容易找到的位置。
</Tip>
