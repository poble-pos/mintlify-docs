管理打印机组，将菜单商品发送至正确的打印机。

**位置：** POS 设备 → Menu Management → Menu Setup → Printer Mapping

<Steps>
<Step title="打开 Printer Mapping">

在 **Menu Setup** 中选择 **Printer Mapping**，打开 **Manage Printer Groups**。

</Step>
<Step title="创建打印机组">

选择 **Create Group**，在 **Create Printer Category** 表单中填写 **Name** 和 **Description**。

<Frame caption="Manage Printer Groups 与 Create Printer Category 表单">
  <img src="/images/menu-management/printer-mapping.png" alt="Manage Printer Groups 与 Create Printer Category 表单" />
</Frame>

</Step>
<Step title="检查打印选项">

需要额外打印时，请查看 **Extra Print Count**。使用表单控件完成组设置。

</Step>
<Step title="检查打印机分配">

检查可用的组和分配控件，确保菜单商品发送至预期的打印机。

</Step>
</Steps>

<Note>
Printer Mapping 用于管理打印机组和分配。硬件与连接设置请使用 POS 中的打印机配置。
</Note>
