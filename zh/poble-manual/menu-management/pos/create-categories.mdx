在 POS 上添加分类或浏览可用分类。

**位置：** POS 设备 → Menu Management → Menu Setup

<Steps>
<Step title="开始创建分类">

在 **Menu Setup** 中选择 **Categories** 旁的 **+**。

</Step>
<Step title="填写分类信息">

在 **Create Category** 的 **Item Name** 中输入必填的分类名称。按需添加图片、**POS Display Name** 和 **Description**。

<Frame caption="POS 上的 Create Category 对话框">
  <img src="/images/menu-management/pos-create-category.png" alt="POS 上的 Create Category 对话框" />
</Frame>

</Step>
<Step title="创建或浏览分类">

选择 **Create** 保存新分类。如需选择已有分类，请使用 **Browse Available Categories**。

</Step>
</Steps>
