直接在 POS 上输入菜单商品信息。

**位置：** POS 设备 → Menu Management → Menu Setup

<Steps>
<Step title="选择分类">

选择商品所属分类，然后选择 **Menu Items** 旁的 **+**。

</Step>
<Step title="填写基本信息">

检查 **Category**，填写 **Item Name**、**Price** 和 **Tax Option**。按需添加图片、条码、**POS Display Name** 和 **Description**。

<Frame caption="包含 Basic Info 与可选设置的 Create Menu Item 对话框">
  <img src="/images/menu-management/pos-item-details.png" alt="包含 Basic Info 与可选设置的 Create Menu Item 对话框" />
</Frame>

</Step>
<Step title="检查其他设置并创建">

按需检查 **Item Options**、**Print Options** 和 **Advanced Options**，然后选择 **Create**。

</Step>
</Steps>

<Tip>
创建商品前，请检查所选分类和商品价格。
</Tip>
