将公司菜单商品归入 Coffee、Food 或 Drinks 等分类。

**位置：** 管理后台 → 公司视图 → POS → Menu Settings

<Steps>
<Step title="开始创建分类">

选择分类列表上方的 **Create Category**。

<Frame caption="公司菜单分类与 Create Category 按钮">
  <img src="/images/menu-management/company-category-list.png" alt="公司菜单分类与 Create Category 按钮" />
</Frame>

</Step>
<Step title="填写分类信息">

填写 **Name**。按需添加图片、**POS Display Name** 和 **Description**。

<Frame caption="包含 Available Stores 的 Create Category 表单">
  <img src="/images/menu-management/company-create-category.png" alt="包含 Available Stores 的 Create Category 表单" />
</Frame>

</Step>
<Step title="选择可用门店并创建">

在 **Available Stores** 下选择应使用该分类的门店，然后选择 **Create**。

</Step>
</Steps>

<Tip>
请使用清晰的分类名称，方便员工快速查找商品。
</Tip>
