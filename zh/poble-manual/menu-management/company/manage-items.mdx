创建公司菜单商品，并更新名称、价格、分类等信息。

**位置：** 管理后台 → 公司视图 → POS → Menu Settings

<Steps>
<Step title="选择分类">

从列表选择分类，其商品会显示在旁边。选择 **Create Menu Item** 添加商品。

<Frame caption="Coffee 分类中的商品与 Create Menu Item 按钮">
  <img src="/images/menu-management/company-item-list.png" alt="Coffee 分类中的商品与 Create Menu Item 按钮" />
</Frame>

</Step>
<Step title="填写商品信息">

选择 **Item Type**，填写 **Name** 和 **Price**。按需添加图片、**POS Display Name**、**Description**、**Tags** 及条码信息。检查 **Tax Options** 后选择 **Create**。

<Frame caption="公司管理后台的 Create Menu Item 表单">
  <img src="/images/menu-management/company-create-item.png" alt="公司管理后台的 Create Menu Item 表单" />
</Frame>

</Step>
<Step title="编辑已有商品">

从分类中打开商品，更新相关字段。需要移动分类时使用 **Change Category**，再通过页面控件应用更改。

<Frame caption="公司菜单商品详情与 Change Category 按钮">
  <img src="/images/menu-management/company-edit-item.png" alt="公司菜单商品详情与 Change Category 按钮" />
</Frame>

</Step>
</Steps>

<Note>
创建和编辑界面的字段标签可能不同。应用更改前请检查所选商品及价格。
</Note>
