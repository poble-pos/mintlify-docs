Cancel the current order and record the reason.

**Where:** POS device → sales screen → Cancel Order

<Steps>
<Step title="Select Cancel Order">

Review the current order, then select **Cancel Order** at the bottom-left of the sales screen.

</Step>
<Step title="Enter the reason">

In the **Cancel Order** window, explain why the order is being cancelled, such as an incorrect order or a customer request.

<Frame caption="Cancel Order dialog with a reason field, Cancel, and Confirm">
  <img src="/images/sales-payments/cancel-order.png" alt="Cancel Order dialog with a reason field, Cancel, and Confirm" />
</Frame>

</Step>
<Step title="Confirm the cancellation">

Select **Confirm** to proceed. Select **Cancel** to close the dialog without confirming the cancellation.

</Step>
</Steps>

<Warning>
Use **Cancel Order** for the entire current order. To remove only one item, use the item’s quantity controls and delete icon.
</Warning>
