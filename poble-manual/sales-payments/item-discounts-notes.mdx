Apply a discount or add a note to a selected item before payment.

**Where:** POS device → sales screen → item price arrow

<Steps>
<Step title="Expand the item controls">

Select the arrow beside the item price in the order panel. The **Discount** and **Note** controls appear.

<Frame caption="Expanded item row showing Discount and Note controls">
  <img src="/images/sales-payments/item-discount-note.png" alt="Expanded item row showing Discount and Note controls" />
</Frame>

</Step>
<Step title="Apply a discount">

Select **Discount**. Choose a pre-configured discount or enter a custom percentage on the **Percentage** tab, then select **Apply Discount**.

<Frame caption="Item discount window with presets, percentage keypad, and Apply Discount">
  <img src="/images/sales-payments/item-discount-settings.png" alt="Item discount window with presets, percentage keypad, and Apply Discount" />
</Frame>

</Step>
<Step title="Check the result">

Review the discount and updated item price in the order panel. The example shows a 10% discount reducing an item from $4.00 to $3.60, with the order total updated accordingly.

<Frame caption="Order panel showing an applied item discount and updated total">
  <img src="/images/sales-payments/discount-applied.png" alt="Order panel showing an applied item discount and updated total" />
</Frame>

</Step>
<Step title="Add an item note">

Select **Note** on the relevant item. Enter the note and apply it using the controls shown in the note window.

</Step>
</Steps>

<Note>
An item discount applies to the selected item. Review order-level adjustments separately on the **Checkout** screen.
</Note>
