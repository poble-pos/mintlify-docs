Open the sales screen from the POS main page.

**Where:** POS device → main screen → Start Sales

<Steps>
<Step title="Check the store">

On the POS main page, check the store name before taking orders.

<Frame caption="POS main page with the Start Sales button">
  <img src="/images/sales-payments/start-sales.png" alt="POS main page with the Start Sales button" />
</Frame>

</Step>
<Step title="Start taking orders">

Select **Start Sales** to open the sales screen.

</Step>
</Steps>
