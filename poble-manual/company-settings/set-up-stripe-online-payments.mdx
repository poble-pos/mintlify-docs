Set up a Stripe connected account from **Company Settings** to accept online payments.

## Set Up Stripe Online Payments

<Steps>
<Step title="Open Stripe settings">

Select **Company Settings**, then open the **Stripe** tab.

</Step>
<Step title="Begin account setup">

Under **Stripe Connected Account**, select **Create Stripe Account**. The source example shows an **Action required** status before setup.

</Step>
<Step title="Complete the requested setup">

Follow the account setup instructions and provide the details requested in that flow.

</Step>
<Step title="Review account status">

Return to the **Stripe** tab and check the connected-account status. Complete any actions requested on screen.

</Step>
</Steps>
