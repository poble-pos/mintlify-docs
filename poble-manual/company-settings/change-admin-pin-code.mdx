---

Change your admin POS PIN from **Profile**. The source screen lists a PIN field beside each accessible store.

## Change Admin PIN Code

<Steps>
<Step title="Open your accessible stores">

Select **Profile**, then open the **Accessible Stores** tab.

</Step>
<Step title="Enter the new PIN">

Find the relevant store and enter your new PIN in **Pos Pin Code**.

</Step>
<Step title="Apply the change">

Select **Update** beside that store.

</Step>
</Steps>
