Manage printer groups for routing menu items to the appropriate printers.

**Where:** POS device → Menu Management → Menu Setup → Printer Mapping

<Steps>
<Step title="Open Printer Mapping">

In **Menu Setup**, select **Printer Mapping** to open **Manage Printer Groups**.

</Step>
<Step title="Create a printer group">

Select **Create Group**. In the **Create Printer Category** form, enter **Name** and **Description**.

<Frame caption="Manage Printer Groups and Create Printer Category form">
  <img src="/images/menu-management/printer-mapping.png" alt="Manage Printer Groups and Create Printer Category form" />
</Frame>

</Step>
<Step title="Review print options">

Review **Extra Print Count** if additional prints are needed. Complete the group using the controls shown in the form.

</Step>
<Step title="Review printer assignments">

Review the available group and assignment controls so menu items are routed to the intended printers.

</Step>
</Steps>

<Note>
Printer Mapping manages printer groups and assignments. Use the printer configuration available in your POS for hardware and connection settings.
</Note>
