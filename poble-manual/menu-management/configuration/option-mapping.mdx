Link option groups to menu items so customers can customise their orders.

**Where:** POS device → Menu Management → Menu Setup → Option Mapping

<Steps>
<Step title="Open Option Mapping">

In **Menu Setup**, select **Option Mapping** to open **Manage Item Options**.

</Step>
<Step title="Select the menu items">

Choose an **Item Category**, then select the items you want to configure.

</Step>
<Step title="Choose and arrange option groups">

Select the required **Option Groups**. Check **Selected Option Groups** and drag them to change their order.

<Frame caption="Manage Item Options with categories, items, and selected option groups">
  <img src="/images/menu-management/option-mapping.png" alt="Manage Item Options with categories, items, and selected option groups" />
</Frame>

</Step>
<Step title="Save the mapping">

Review the selected items and option groups, then select **Save**.

</Step>
</Steps>

<Warning>
The screen states that setting options here overwrites existing settings. Review the selected items and their current options before saving.
</Warning>
