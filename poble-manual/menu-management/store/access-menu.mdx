Select a store and view the menu items available at that location.

**Where:** Backoffice → selected store → POS → Menu Settings

<Steps>
<Step title="Choose a store">

Use the company/store selector to select the location you want to manage. Check the store name displayed in the header.

<Frame caption="Selected company and store in the backoffice header">
  <img src="/images/menu-management/store-selector.png" alt="Selected company and store in the backoffice header" />
</Frame>

</Step>
<Step title="Open the store menu">

Go to **POS → Menu Settings**. The categories and menu items shown are associated with the selected store.

<Frame caption="Store-specific menu categories and items">
  <img src="/images/menu-management/store-menu-list.png" alt="Store-specific menu categories and items" />
</Frame>

</Step>
</Steps>

<Tip>
Check the store name before editing prices or adding items for a franchise location.
</Tip>
