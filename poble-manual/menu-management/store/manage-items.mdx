Manage menu categories and items for an individual store.

**Where:** Backoffice → selected store → POS → Menu Settings

<Steps>
<Step title="Select a category">

Open the selected store’s **Menu Settings** and choose the category you want to manage.

</Step>
<Step title="Add a menu item">

Select **Create Menu Item**. Enter the item name, price, category, and other details requested in the form, then complete the creation using its controls.

<Frame caption="Store menu items and Create Menu Item button">
  <img src="/images/menu-management/store-create-item.png" alt="Store menu items and Create Menu Item button" />
</Frame>

</Step>
<Step title="Edit an existing item">

Open the item from the list and update its name, price, category, or other settings as needed. Review and apply the changes for the selected store.

</Step>
<Step title="Edit a category">

To change the category itself, open the **…** menu beside its name and select **Edit Category**.

<Frame caption="Category menu with Edit Category and Delete Category actions">
  <img src="/images/menu-management/store-edit-menu.png" alt="Category menu with Edit Category and Delete Category actions" />
</Frame>

</Step>
</Steps>

<Tip>
Use **Edit Category** to change a category and open the menu item to change its item details.
</Tip>
