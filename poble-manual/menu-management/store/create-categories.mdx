Create a menu category for the selected store.

**Where:** Backoffice → selected store → POS → Menu Settings

<Steps>
<Step title="Open the category form">

Check that the correct store is selected, then select **Create Category**.

</Step>
<Step title="Enter category details">

Enter **Name**. Add an image, **POS Display Name**, and **Description** if needed.

<Frame caption="Create Category form in the selected store">
  <img src="/images/menu-management/store-create-category.png" alt="Create Category form in the selected store" />
</Frame>

</Step>
<Step title="Create the category">

Review the details and select **Create** in the category form.

</Step>
</Steps>

<Note>
The company category form includes **Available Stores**. In the store view, check the location in the header before creating a category.
</Note>
