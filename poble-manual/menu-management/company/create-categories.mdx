Organise company menu items into categories such as Coffee, Food, or Drinks.

**Where:** Backoffice → company view → POS → Menu Settings

<Steps>
<Step title="Start a category">

Select **Create Category** above the category list.

<Frame caption="Company menu categories and Create Category button">
  <img src="/images/menu-management/company-category-list.png" alt="Company menu categories and Create Category button" />
</Frame>

</Step>
<Step title="Enter category details">

Enter **Name**. Add an image, **POS Display Name**, and **Description** if needed.

<Frame caption="Create Category form with Available Stores">
  <img src="/images/menu-management/company-create-category.png" alt="Create Category form with Available Stores" />
</Frame>

</Step>
<Step title="Choose available stores and create">

Under **Available Stores**, select the locations that should have access to the category. Select **Create**.

</Step>
</Steps>

<Tip>
Use clear category names so staff can find items quickly.
</Tip>
