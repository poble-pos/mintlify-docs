Create option groups and choices for sizes, flavours, and other item customisations.

**Where:** Backoffice → company view → POS → Item Options

<Steps>
<Step title="Open the options list">

Expand **POS** and select **Item Options**. The page heading is **Options**.

</Step>
<Step title="Create an option group">

Select **Create Option** and enter a group name, such as **Flavoured** or **Hot / Iced**.

</Step>
<Step title="Add choices">

Select the group, then select **Add New Item** to add choices such as Vanilla, Caramel, or Hazelnut. Set an additional price for each choice if required.

<Frame caption="Option groups and choices in the backoffice">
  <img src="/images/menu-management/company-options.png" alt="Option groups and choices in the backoffice" />
</Frame>

</Step>
<Step title="Update existing options">

Use the edit icon beside an option group to update it. Review the group and its choices after making changes.

</Step>
</Steps>

<Note>
Creating an option group and assigning it to a menu item are separate tasks. Use **Option Mapping** to connect options to items.
</Note>
