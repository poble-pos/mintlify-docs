Add a category or browse available categories from the POS.

**Where:** POS device → Menu Management → Menu Setup

<Steps>
<Step title="Start a category">

Select the **+** button beside **Categories** in **Menu Setup**.

</Step>
<Step title="Enter category details">

On **Create Category**, enter the required category name in **Item Name**. Add an image, **POS Display Name**, and **Description** if needed.

<Frame caption="Create Category dialog on the POS">
  <img src="/images/menu-management/pos-create-category.png" alt="Create Category dialog on the POS" />
</Frame>

</Step>
<Step title="Create or browse categories">

Select **Create** to save the new category. To choose an existing category instead, use **Browse Available Categories**.

</Step>
</Steps>
