Create and organise option groups and choices on the POS.

**Where:** POS device → Menu Management → Option Setup

<Steps>
<Step title="Open Option Setup">

Select **Option Setup** from the menu management sidebar.

</Step>
<Step title="Manage option groups">

Select a group to view its choices. Use the **+** button beside **Options Group** to begin adding another group.

<Frame caption="POS Option Setup with option groups and option items">
  <img src="/images/menu-management/pos-option-setup.png" alt="POS Option Setup with option groups and option items" />
</Frame>

</Step>
<Step title="Manage choices">

Use the **+** button beside **Option Items** to add a choice. Use the edit icon beside an existing choice to update it, and drag its handle to change the order.

</Step>
</Steps>

<Note>
Use **Option Mapping** to assign the option groups to the items that should offer them.
</Note>
