Enter menu item details directly on the POS.

**Where:** POS device → Menu Management → Menu Setup

<Steps>
<Step title="Select a category">

Choose the category for the item, then select the **+** button beside **Menu Items**.

</Step>
<Step title="Complete Basic Info">

Review **Category** and enter **Item Name**, **Price**, and **Tax Option**. Add an image, barcode, **POS Display Name**, and **Description** if needed.

<Frame caption="Create Menu Item dialog with Basic Info and optional settings">
  <img src="/images/menu-management/pos-item-details.png" alt="Create Menu Item dialog with Basic Info and optional settings" />
</Frame>

</Step>
<Step title="Review other settings and create">

Review **Item Options**, **Print Options**, and **Advanced Options** if required, then select **Create**.

</Step>
</Steps>

<Tip>
Check the selected category and item price before creating the item.
</Tip>
