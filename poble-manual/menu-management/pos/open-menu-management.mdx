Open the menu tools from the POS main screen.

**Where:** POS device → main screen → Menu Management

<Steps>
<Step title="Open the POS main screen">

Go to the POS main screen for the store you want to manage.

<Frame caption="POS main screen showing Menu Management and Settings">
  <img src="/images/menu-management/pos-settings.png" alt="POS main screen showing Menu Management and Settings" />
</Frame>

</Step>
<Step title="Select Menu Management">

Select **Menu Management** to access **Menu Setup**, **Option Setup**, **Prepaid Setup**, and **Menu Layout**.

<Frame caption="POS Menu Setup with categories and menu items">
  <img src="/images/menu-management/pos-add-category-item.png" alt="POS Menu Setup with categories and menu items" />
</Frame>

</Step>
</Steps>

<Note>
**Menu Management** and **Settings** are separate controls on the POS main screen. Use **Menu Management** for the menu tools in these guides.
</Note>
